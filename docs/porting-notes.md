# 移植メモ(技術詳細)


MZ-700/1500版(`M7*.ASM`)を土台に、機種依存部を `M25*.ASM` に置き換えた移植です。共通部 `LD*.ASM` は無改造です。
実IPL ROMでブートする mz2500-web-emulator(実エミュレータ核)上で、次を確認済みです。
起動 → バナー → `DIR` → `COPY`(読み書き) → `FORMAT.COM`(物理+論理フォーマット)。
X1/MZ-700のLSXで作った**標準形式の2D/2DD(512バイト×9セクタ、BPBあり)をそのまま読み書き**できます。

## ドライブ
- A:/B: = 内蔵FDD 1/2。メディア交換時に論理セクタ0のBPBを読んで、2D(40cyl)/2DD(80cyl)を自動判別
- 標準ディスクの空き容量: 2D = **362496**、2DD = **730112**(X1/MZ-700のLSXと同じ値)
- C:/D: = 外付けFDD 3/4(DCHのドライブ選択ビット b1-b0=10/11 で選ぶだけ。**実機・エミュレータとも未確認**。エミュレータはFDD 2台なので、実体が無いとき `Error!` で続行できることだけ確認)
- E: = EMM(MZ-1R37。ポートACh/ADh)。起動時に64KB単位で大きさを検出(最大640KB)。**使う前に `FORMAT E:` が必要**(EMMは他のOSも使うため、勝手に初期化しない)。512B/セクタ。640KBで空き648704
- F: = RAMディスク(拡張RAMのページ10h-1Fh = 128KB)。起動時に有無を検出し、タグが無ければ自動でフォーマット(空き125952)。**先頭8バイトのタグ `LSX25RD` が無い内容は消える**。512B/セクタ
- G:/H: は未使用(CMOS/PCGドライブ、割り込みキー入力(USE_8253)は無し)

## 起動の仕組み
標準LSXディスクのレイアウトを保ったまま、MZ-2500のIPLが読める領域を予約セクタ内に確保しています。
```
L0      ブートセクタ(BPB。予約セクタ=36)
L9-17   〔IPL用〕cyl0/head1 を 256B×16 に差し替え(レコード0-15 = IPLヘッダ)
L18-35  〔IPL用〕cyl1 両面を 256B×16 に差し替え(レコード32-63 = 8KBのブートローダ)
L36-41  FAT×2   L42-48 ルートDIR   L49- データ(LD2500.BIN は先頭クラスタ=L49から連続)
```
1. IPLがレコード0(ヘッダ)を読み、ロード開始レコード=32からブートローダ(257バイト)を `8000h` に読んで実行
2. ブートローダが `LD2500.BIN` を標準セクタ(512B、反転バスなのでCPL)で読み、ページ0Ah/0Bhに置いてバンク4/5に割り当て、`8000h` へジャンプ
3. `LD2500.BIN` の `START`(IPLの環境=SP=FC00h・EI・IM2のまま): IOCS `TINIT` → `DI`、SPを `CE00h`、`IM 1`、`C6h`=08h(VBLANKのみ許可。`E1h` bit0 を動かすために必須) → 本体を `CF06h` へ転送して初期化

## ビルド
    [LSX_IMPORT=<原本のシステムD88>] python3 build.py <LSX-Dodgers原本dir> <z88dk-z80asm> <out> [USE_TINIT] [COLS80] [KEEP_ENV]
- 推奨(80桁): `USE_TINIT COLS80 KEEP_ENV` / 40桁: `USE_TINIT KEEP_ENV` / IOCS無し: 指定なし
- 出力: `<out>/LSX2500.d88`(起動ディスク)、`LD2500.BIN`、`boot_payload.bin`
- z88dk の z80asm を使用。`PHASE`/`$$` 等の差は `tools/ld2z80asm.py` が変換(同じ変換でMZ-700版を組むと原本とバイト一致)
- `tools/make_blank_disk.py out.d88 {2d|2dd}` : X1/MZと同じ形式の空ディスクを作る

## デバッグで判明した重要事項
1. **IOCSを呼ぶときのスタックをバンク6(C000h-DFFFh)に置かない。** IOCSはVRAMアクセスのためバンク6にテキストVRAMを出し入れする。ブート標準のSP=FC00hのまま呼ぶ。
2. **VRAMセルは文字高さで変わる**: 16ライン文字(`F7h` bit0=0、ブート時)は Text1=`(c&3Fh)*4`、消去/空白=`80h`、Text2=`8Ch+(c>>6)`。`+2`(R=1)は8ライン用で、16ラインで使うと上下2回描かれる。
3. **FDC**: 全レジスタが反転バス。コマンド/トラック/セクタ/シーク先に加え、**データもCPLして読み書き**(ディスク上は素のデータ。X1/MZ-700のイメージと互換)。ヘッド: `DDh` bit0 = トラックの偶奇(偶数=ヘッド0)。
4. **IPL用トラックだけ別規則**: IPLレコード r は D88の `r XOR 10h` の位置(r=0は cyl0/head1/sec1)、データは補数(IPLが `IPLPRO` を検査する前提)。標準領域とは混ぜない。
5. `FORMAT.COM` は**ドライブの現在のDPB**でフォーマットする。メディアを一度も読んでいない状態(初期DPB=2D)で実行すると2D用のFATを書くので、先に `DIR B:` などでメディアを読ませる(原本のLSXと同じ挙動)。
6. 物理フォーマット: `FORMAT` で種別を選ぶ(`0`=2D, `1`=2DD)。未フォーマットのD88でも可(エミュレータで確認、2D 空き362496 / 2DD 730112)。実機のWrite Trackは未確認。
7. キー走査は `E8h` を読み戻して上位3ビットを保持し、bit4=1+列を書く。

## 未対応・未確認
- ROMなしの組み込みIPL(dummy IPL)ではブートしません(ペイロードの固定位置が標準LSXの先頭トラックと衝突するため)
- F1〜F10/GRAPH/HELPキー(LOCK・カナは対応)
- `MON` はIOCSのROMモニタ(`D`でメモリ表示、`R`でLSXに戻る)を呼ぶ。エミュレータで往復確認、実機は未確認。TPAのプログラムは消える
- カーソルは約0.5秒ごとに点滅(1文字入力待ちの間。エミュレータで確認、実機の周期は未確認)
- 2HD: MZ-2500に2HDドライブが存在するか(標準は2DDまで。オプションがあるか)は資料で確認できていないため、**実装していない**
- 外付けFDD(C:/D:)、EMM(E:)、拡張RAM(F:)の**実機での動作**。拡張RAMが標準で載っているかも不明(無い場合はF:は無効になる設計だが、その経路はエミュレータで試せていない)
- RAMディスクのRESET後の内容保持(タグがあればフォーマットしない設計)。エミュレータはRESETで拡張RAMも消すため確認できていない
- `E1h` bit0(/VBLANK)は `C6h` bit3 の許可があるときだけ動く。キーリピート/FDCのタイムアウトの時間基準に使うので `C6h`=08h が必須(`docs/hardware-notes.md` §6)
